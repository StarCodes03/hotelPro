# HotelPro — Hotel Management Dashboard

## Project Overview

HotelPro is a web-based hotel management dashboard designed to organize hotel operations such as room management, reservations, billing, guest feedback, and room service.

## Technology Stack

- Next.js
- React
- TypeScript

## Original Project

This repository is a fork of the original project by Emeka Okpaleke.

- **Original repository:** https://github.com/Emeka-Okpaleke/hotel-pro
- **Original demo:** https://hotel-pro-eosin.vercel.app/

The original author and source are acknowledged. Any modifications made for this submission will be documented here.

## Setup

Prerequisites: Node.js and npm.

```bash
npm install
npm run dev
```

Open http://localhost:3000 in your browser.
